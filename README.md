# Doors System

Manage and lock doors in your FiveM server with ease.

## Features

- Lock and unlock doors with a simple key press
- Buy and own doors with in-game currency
- Database integration for persistent door states

## Requirements

- FiveM server with ESX framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Configure the `config.lua` file with your database details
4. Import the `database.sql` file into your MySQL database
5. Add `start doors-system` to your server.cfg file

## Usage

### Player Commands

- Press `E` near a door to lock or unlock it

### Admin Commands

- Use the in-game admin menu to manage doors

## Configuration

Edit the `config.lua` file to customize:

- Interaction distance
- Lock cooldown
- Default door price
- Database connection details
